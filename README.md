# 华医网课件免打扰学习助手

Chrome 扩展，适用于 `*.91huayi.com`。支持课件原速连播、播放保护、自动答题与重考，通过后继续下一课。

当前版本：**1.0.0** · Chrome **120 或更新版本**。

[下载 ZIP 安装包](https://github.com/tnt2ray/huayi-study-assistant/releases/latest) · [安装与使用步骤](安装说明.txt)

## 安装与更新

### 首次安装

1. 将发布的 ZIP **完整解压到固定文件夹**，保留 `icons/` 等全部文件。
2. 在 Chrome 地址栏输入 `chrome://extensions/`，打开右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
4. 在工具栏的扩展菜单中固定助手图标，方便调整设置。
5. 打开或刷新已打开的华医网课件、考试页面。

安装后保留该文件夹，不要移动或删除。源码目录也可直接加载。发布包仅提供 ZIP，需先解压后安装；日常使用无需连接浏览器调试工具。

### 更新已有安装

1. 将新版文件覆盖到**原安装文件夹**，包括 `icons/`。
2. 打开 `chrome://extensions/`，点击助手卡片上的 **重新加载**。
3. 刷新已打开的课件、考试或结果页面，再打开扩展面板确认版本号。

无需卸载或加载第二份。只替换文件不会更新已打开页面中的脚本。

## 设置答题模式

点击扩展图标，设置 **自动答题与交卷** 和 **答题模式**，最后点击 **保存设置**。初始设置为开启、AI 辅助；已有设置继续保留。

### 无 AI · 依次尝试

选择该模式并保存即可，无需运行或配置 Magpie。

新题从 A 开始；每轮交卷后，保留原站确认正确的答案，为错题选择尚未排除的下一选项，直到通过。题号或选项顺序变化时按内容匹配，每轮同时推进所有错题。整个模式不调用 Magpie。

### AI 辅助

1. 启动可访问的 Magpie 服务。
2. 填写 **Magpie 地址**，默认 `http://127.0.0.1:3425`，也可使用其他 HTTP(S) 地址。
3. 点击模型旁的 **刷新**；首次访问自定义地址时，按 Chrome 提示授权。
4. 选择服务返回的模型，点击 **保存设置**。

已确认正确的题直接填写；其余题交给模型，已知错选项不再发送。存疑时采用模型返回的最可能答案，详情可在页面助手中展开查看。

更换模式、地址或模型并保存后，尚未交卷的活动任务会按新设置重新处理。已暂停的任务需主动点 **重试**。

## 日常使用

登录华医网，进入课件并正常开始播放。助手减少随机签到弹窗造成的中断，视频保持原速播放。

自动处理开启时：

1. 视频自然结束后，通过原站入口进入本课考试；没有考试入口时继续下一课。
2. 填写完成后倒计时 **5 秒交卷**。
3. 未通过且能完整识别对错时，倒计时 **5 秒重考**。
4. 通过后倒计时 **3 秒进入下一课**：优先使用原站入口，没有入口时访问课件页记录的下一课地址。

需要手动操作答案时，先点页面助手的 **暂停**；继续时点 **重试**。普通点击、按键和改选答案不会暂停自动处理。要关闭自动答题，在扩展面板关闭开关并保存。

工具栏角标表示播放保护状态，不表示考试结果：

| 角标 | 含义 |
| --- | --- |
| ON | 播放保护中 |
| WAIT | 暂时保护起播或切集等待过程 |
| ! | 连接或播放异常，请查看原站提示 |
| 无角标 | 当前未启用播放保护 |

## 常见情况

- **没有自动开始**：确认开关已开启并保存；更新后需重新加载扩展并刷新页面。AI 模式还需能连接 Magpie 并选择可用模型。
- **提示上一轮已交卷**：回到结果页，点击原站 **重新考试**；刷新答题页不等于开始新一轮。
- **模型不可用或列表为空**：检查地址和服务状态，刷新列表并重新选择模型。
- **助手暂停或页面没有跳转**：查看助手及原站提示，处理后再重试。登录、人脸验证和付费提示需自行处理。

目前只支持文字单选题。无法确认逐题对错、题目发生变化、反馈矛盾或选项耗尽时会停止；不会无限重复同一组答案。

**使用期间保持电脑不锁屏、不待机、不休眠，勿合盖，以免被服务器判定登录失效。** 扩展不修改播放速度、学习时长或完播上报数据。

## 数据保存

设置保存在本机。跨轮匹配使用题干与选项摘要、原站对错反馈和提交状态，不持久保存题目或答案原文。摘要记录随浏览器会话保存并限时清理，重新加载扩展或重启浏览器后可能需要重新积累。

AI 模式仅将待处理题目的题号、题干和选项发送给所配置的 Magpie，不附带账号、Cookie 或令牌；Magpie 自身的日志由其配置决定。扩展不再采集或写入诊断日志。

## 从源码打包

在项目目录运行：

```sh
python3 tools/package_extension.py
```

仅生成 `dist/华医网课件免打扰学习助手-<版本>.zip`，包内含运行文件和 `安装说明.txt`。安装、更新、设置及使用说明统一写在 `安装说明.txt` 中；本 README 仅保留在源码目录，不打入 ZIP。

打包使用 Python 标准库，核对 ZIP CRC、文件清单及源码一致性，结果和 SHA-256 输出到终端；不生成 CRX、签名或单独校验文件，不执行测试用例。
